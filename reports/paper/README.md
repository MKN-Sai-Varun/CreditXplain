# Paper figures and tables

Everything here is generated by `python3 -m src.paper_figures` from the files in `reports/` and
`models/final_model_card.json`. Do not edit these files by hand: change the source, re-run the
script, and upload again. `numbers.json` holds the numbers quoted in the text, with their sources.

## Setting up the Overleaf project (IEEE Access template)

1. In the Overleaf project, create two folders: `figures` and `tables`.
2. Upload `figures/*.pdf` into `figures/`. The PNG copies are for slides only.
3. Upload `tables/*.tex` into `tables/`. The `.md` copies are for reading on GitHub.
4. Upload `references.bib` to the project's top level.
5. In the main `.tex` file:
   - add `\usepackage{url}` next to the other packages;
   - replace the whole `\begin{thebibliography} ... \end{thebibliography}` block with:
     ```latex
     \bibliographystyle{IEEEtran}
     \bibliography{references}
     ```
6. Click **Recompile**. References appear once they are cited with `\cite{...}`.

Before submission, check every entry of `references.bib` on Google Scholar or the publisher's page,
and complete the author lists marked `and others` (IEEE lists up to six authors before \emph{et al.}).

## Figures

Use the template's own `\Figure` command for every figure: the IEEE Access class captions figures only through it
(a standard `figure` or `figure*` block stops with an undefined `\xfigwd` error). The class sizes each figure from the
PDF's own width: the page-wide figures are 7.16 in and the column figures 3.5 in.
For a page-wide figure the class sets the caption on a single line and does not wrap it, so keep those
captions under about 130 characters; column-wide captions wrap normally.

## IEEE checks already applied

- Figures are vector PDFs with embedded fonts (Arial), text 6.5–8 pt, sized to one column (3.5 in) or the page (7.16 in).
- Colours stay distinguishable in greyscale print (blue and orange differ in lightness), and every bar carries a label or legend.
- Captions sit below figures and above tables; no borders around figures.
